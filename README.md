# NoelClark.com

## Overview

NoelClark.com is a handcrafted storytelling website built with HTML, CSS, and JavaScript.

It is intentionally not designed like a traditional website.

Visitors should feel like they are entering someone's mind rather than navigating software.

The project emphasizes curiosity, restraint, thoughtful motion, beautiful typography, and authentic writing.
