This document provides the current authoritative project state for NoelClark.com Version 1.0. This document is descriptive, not creative. It records the current authoritative state of the project but does not itself create new creative, architectural, or engineering decisions.

Before proposing new features, redesigns, interactions, or architecture, consult those principles first. If a proposal conflicts with the Constitution, the Constitution takes precedence unless it is formally amended.

* what the project is

* what has been superseded
* what remains unresolved

* what is known about the current production repository
* which additional authority documents are required for different kinds of work
* what must happen before implementation may proceed

This document is a handoff.

It does not replace the creative Treatments.

It does not replace engineering plans.

It records the current project state established by the governing authorities.

Where the governing authorities disagree, this document records the disagreement rather than silently resolving it.
