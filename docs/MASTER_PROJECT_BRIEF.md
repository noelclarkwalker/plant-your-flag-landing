# MASTER_PROJECT_BRIEF

Version 1.0

This document is the source of truth for NoelClark.com.

If future conversations conflict with this document, update this document intentionally before changing the project.

---

# Philosophy

The code exists to serve the experience.

If implementation details conflict with the intended emotional experience, improve the implementation rather than changing the story.

We are not building a website.

We are building the architecture of curiosity.

The browser becomes our design partner.

If the browser proves us wrong, we improve the code.

Never redesign the architecture unless there is a compelling technical reason.

Complexity must be earned.

No feature creep.

The story always comes first.

---

# Development Rules

Treat GitHub as the source of truth.

Build feature-by-feature.

Every feature ends with:

* Test
* Screenshot
* Commit
* Push

Every commit represents one meaningful milestone.

Always provide complete files whenever practical.

Do not split production files across multiple responses.

Assume the user has very little coding experience.

Explain every click, save, commit, and push.

Never skip steps.

---

# Repository Philosophy

Repository structure is locked.

Do not reorganize folders without a compelling technical reason.

Preserve existing HTML architecture whenever practical.

Prefer improving existing code over rewriting working code.

Prototype first.

When a prototype earns its place, merge it into production.

Do not regenerate production code from memory if an approved prototype exists.

---

# Visual Philosophy

The website should begin with familiarity.

Then quietly become something unexpected.

It should never feel like a traditional portfolio.

It should feel like entering another person's world.

The design should communicate wonder before explanation.

Motion should feel inevitable rather than flashy.

Subtle is almost always better than obvious.

Scene 2

Static social-media-inspired status.

Handle:

@noelclarkdotcom

Name:

NOÈL CLARK

The first line reads:

"There was a time when the internet felt like wandering into someone's world..."

The profile ring glows subtly from the moment it appears.

The card has a slight hover lift.

The status is intentionally familiar.

It invites the visitor.

It does not explain the website.

---

Story

The social interface surrenders and fades.

The visitor moves directly into the Manifesto — one continuous editorial composition.

The Manifesto concludes with the approved declaration, including:

"I'm planting my flag."

There is no separate mandatory visitor room between Manifesto and Portal.

---

Portal

The watercolor NC monogram becomes the threshold.

The NC monogram is the Portal.

The Story Ring is not Portal.

The period remains ordinary punctuation.

Crossing through Portal is voluntary.

Portal owns passage.

Portal does not reveal the Geography of Curiosity.

It carries the visitor to the threshold of something beyond what they can yet perceive.

---

Emergence

Emergence owns arrival.

Emergence is the visitor's first experience of the Geography of Curiosity.

Deer and the natural coexistence of seemingly unrelated things belong here — not to a mandatory pre-Manifesto memory sequence.

Every entry into Emergence begins at night.

The Geography already exists beyond what the visitor can presently perceive.

Awareness broadens perception of that existing world.

The environmental arc progresses from darkness through dawn into daylight and full illumination while the visitor remains free to explore.

Full illumination renders the Geography indistinguishable within an entirely white field.

Closing PLANT YOUR FLAG — black typography on that white field — becomes perceptible as a personal invitation to continue.

This closing PLANT YOUR FLAG is distinct from the opening PLANT YOUR FLAG.

Visitors should feel as though they have arrived somewhere that existed before they could see it.

---

Wander

After the opening experience completes, the visitor is free to explore NoelClark.com.

Wander does not automatically require another cinematic scene.

The website reveals journals, photography, art, music, curiosity, ideas, and unexpected connections.

Navigation is globally available from initial arrival and remains quietly present throughout Feature 01 and onward (see `PORTAL_TREATMENT.md` Part Two).

The visitor is free to wander.

---

Returning Visitors

Returning visitors may skip directly into the website.

First-time visitors always experience the complete journey.

---

Engineering Workflow

Creative decisions happen before code.

Production code is generated one complete file at a time.

Prototype work should be preserved whenever possible.

Do not discard approved visual work without a compelling technical reason.

Every production file should be internally consistent and ready to paste into the project.

Version 1.0 is the goal.

Do not optimize endlessly.

When something passes the vibe test, lock it and continue building.
